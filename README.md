# 10.css

> A Windows 10 style CSS framework with icons, dark theme and Fluent animations.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![npm version](https://badge.fury.io/js/win10-css.svg)](https://www.npmjs.com/package/win10-css)

## Features

- 🎨 **Windows 10 design** — authentic look inspired by Fluent Design System
- 🌙 **Dark theme** — toggled with `.dark-theme` class or auto-detected from system
- ✨ **Animations** — window open/close, button ripple, progress shine, checkbox transitions
- 🔤 **Icons** — Segoe MDL2 Assets (native on Windows 10) with CDN fallback
- 📦 **Zero dependencies** — pure CSS, no JavaScript required
- ♿ **Accessible** — respects `prefers-reduced-motion`
